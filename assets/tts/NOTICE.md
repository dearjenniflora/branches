# 本地配音资产

- 浏览器推理由 `@diffusionstudio/vits-web` 1.0.3（MIT）和 `onnxruntime-web` 1.18.0（MIT）提供。
- 中文音素处理使用 `@diffusionstudio/piper-wasm` 1.0.0。模型为 `zh_CN-huayan-x_low`，来源及原始声明见 `models/zh/zh_CN/huayan/x_low/NOTICE.md` 与 `MODEL_CARD`。
- 模型文件、WASM 和 JavaScript 均由本网站提供；配音在访客设备上运行，文本不会发送给付费配音 API。

模型卡标注训练数据集许可为 `Unknown`。这项配音目前用于产品演示；在用于商业交付前需要确认模型及数据的使用条款，或换用许可明确的中文语音模型。
